## 1. 게임 기본 이해 (덱 빌딩에 필요한 것만)

| 항목 | 내용 |
|---|---|
| 덱 | 12장, 같은 카드 중복 불가 |
| 판 | 기본 6턴. N턴에 N에너지 (로케이션·카드 효과로 변동 가능) |
| 승리 조건 | **상대보다 더 많은 로케이션에서 이기면 승리** (2승은 물론 1승 2무도 승리). 이긴 로케이션 수가 같으면 총 파워 합으로 판정 (Bar With No Name 같은 예외 로케이션 있음) |
| 로케이션 | 1·2·3턴에 하나씩 공개. 덱 플랜을 망가뜨릴 수 있어 유연성이 중요 |
| 공개 순서(우선권) | 이기고 있는 로케이션이 많은 쪽 → 같으면 총 파워가 높은 쪽 → 그것도 같으면 무작위. On Reveal 상호작용에 영향 |
| 큐브(랭크 점수) | 기본 1큐브. **스냅은 각자 1회**, 스냅하면 다음 턴 시작 시 판돈 2배 → 상대는 그 전에 후퇴하면 기존 판돈만 잃음. 마지막 턴에 판돈 자동 2배. 최대 8큐브. 지는 판은 일찍 **후퇴**해서 손실 최소화 |
| 랭크 | 1~100, **100 도달 시 Infinite**. 승률보다 **평균 큐브(큐브 레이트)**가 랭크업 속도를 결정 |
| 카드 풀 (획득 분류) | 스타터 카드 별도 + 컬렉션 레벨에 따라 Series 1~5 순서로 획득. Series 4~5는 희귀 (신규 카드는 주로 Series 5로 나왔다가 나중에 하향) |

### 용어 구분
- **능력 발동 시점**: On Reveal(공개 시), Ongoing(지속), Activate(발동), Game Start(게임 시작), End of Turn(턴 종료)
- **메커니즘**: Destroy(파괴), Discard(버리기), Move(이동), 생성 카드(created — 덱 밖에서 만들어진 카드)
- **카드 유형**: Skill
- **시즌 키워드**: Horde (뱀파이어 대 좀비 시즌, 좀비 계열)

### 덱 빌딩 기본 원칙
1. **코어 4~6장**: 덱의 승리 플랜(시너지 엔진 + 페이오프)
2. **커브**: 1~6턴에 에너지를 낭비 없이 쓰는 배치. 특히 5~6턴 마무리 콤보
3. **유연 카드/테크 2~3장**: 메타 대응 (아래 '테크 카드' 참고)
4. **큐브 관점**: 이길 판 크게(스냅), 질 판 작게(후퇴). 덱이 판세를 얼마나 일찍 읽을 수 있는지가 중요

### 현재 메타에서 자주 보이는 테크/견제 카드
- **Shadow King**: 이 로케이션 카드들의 파워를 기본값으로 리셋 (양쪽 모두. Ongoing 버프는 지속 효과라 다시 적용됨, Luke Cage로 막을 수 없음)
- **Mobius M. Mobius**: 내 코스트 증가 방지 + 상대 코스트 감소 차단 (11/12 너프: 3/3 → 3/2)
- **Cosmo**: 이 로케이션 On Reveal 봉쇄 (양쪽 모두)
- **Luke Cage**: 내 카드 파워 감소 방지
- **Enchantress**: 이 로케이션 Ongoing 능력 제거 (**내 카드도 포함**)
- **Rogue**: 이 로케이션의 적 Ongoing 카드 1장의 능력을 빼앗음

**주의**
- **OTA 이전 판 혼입**: SC·UT는 집계 기간에 11/12 OTA 이전 판이 섞여 있을 가능성이 큼. SV는 "최근 밸런스 변경 영향 덱 제외" 정책을 명시하지만 Mobius / Zombie Scarlet Witch 포함 덱이 목록에 남아 있어 실제 처리 방식은 불명확.
- **OTA 영향 방향은 추정**: 너프 덱은 약해지고 버프 덱은 강해지는 게 일반적이지만, 상대 덱 분포도 함께 바뀌므로 실제 순효과는 다음 주 데이터로 확인해야 함.
- 출처마다 모집단이 달라 **같은 덱도 승률이 10%p 이상 차이** 남 (예: High Evo — UT 73.4% vs SV 59.8%).
- 표본이 작은 덱(수백 판 이하)은 변동 폭이 큼.
- **SC OTA 결과(OTA 전 → 후)**: Captain Britain 승률 51.0 → 53.9%, 점유율 10.2 → 15.0% / Mobius 52.7 → 50.0%, 15.5 → 11.3% / Zombie Scarlet Witch 55.0 → 54.4% (영향 작음) / Mister Sinister 45.7 → 49.9%. OTA 후 이틀치 표본.

### 페이지 표시 규칙 (2026-11-14 추가)
- 승률·판수 = **SnapVault 랭크 7일, 12장 완전 일치**. 플렉스 슬롯은 실제 빌드별로 나눠 각각 대조
- **랭크 7일 100판 미만 빌드는 제외** (사용자 요청). 덱의 모든 빌드가 미달이면 덱 자체를 제외
- **미보유 카드가 있는 빌드의 예측 승률** (`tools/build_data.py`의 `predict`, Codex 리뷰 반영)
  1. 같은 계열 = 원본과 12장 중 8장 이상 겹치는 랭크 7일 리스트
  2. 근거 확인 = 미보유 카드 각각, 그리고 미보유 카드를 **모두** 뺀 같은 계열 전적이 각각 100판 이상. 미달이면 **예측하지 않음**
  3. 대체 카드 = 미보유 카드를 모두 뺀 같은 계열 리스트에 **실제로 가장 많이 들어간 보유 카드** (30판 이상) → 동시 사용 근거 확보
  4. 기준 승률 = 원본 승률을 같은 계열 평균 쪽으로 축소 (가상 100판)
  5. 카드별 기여도 = 원본과 6장 이상 겹치는 리스트로 가중 릿지 회귀 (겹칠수록 가중치 큼, λ=200판, 수렴할 때까지 반복)
  6. 예측 = 기준 승률 + Σ(들어가는 카드 기여 − 빠지는 카드 기여). **기준보다 높게는 잡지 않음**. 같은 대체 12장이 여러 덱에서 나오면 판수가 많은 원본 기준으로 통일
  - 한계: 상관관계 기반 추정(인과 아님), 플레이어 실력·랭크 차이 미통제
- 덱 정렬 = 내가 기대할 수 있는 승률 순 (바로 사용 = 실제 승률, 미보유 = 예측 승률, 예측 불가 = 맨 뒤). **승률 차이 2%p 이내면 1%p당 100판 이상 많은 덱을 위로** (사용자 규칙). 승률 옆 ±는 95% 오차 범위
- 덱 코드 = 카드별 게임 코드(`IrnPtrtB` 형식)를 쉼표로 이어 base64. SnapVault·MSZ 덱 코드 15개를 풀어서 같은 형식임을 확인
